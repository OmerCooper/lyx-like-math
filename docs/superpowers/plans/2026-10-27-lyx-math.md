# LyX Math for Obsidian Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Obsidian plugin that gives LyX-style WYSIWYG math entry (Ctrl+M inline, Ctrl+Shift+M display, Space finishes `\commands`, click-to-edit, LyX formula panel) while the note keeps plain `$...$` / `$$...$$` LaTeX.

**Architecture:** Pure TypeScript modules (`src/latex/*`, `src/panel/symbols.ts`, `src/editor/keys.ts`) hold all text logic and are unit-tested with vitest. A thin DOM/CodeMirror layer opens a MathLive `<math-field>` as a CM6 replace-widget over the formula range; the document is changed once, on commit. A sidebar `ItemView` renders the formula panel.

**Tech Stack:** TypeScript, esbuild (Obsidian sample-plugin setup), `obsidian` API, `@codemirror/view` + `@codemirror/state` (externals provided by Obsidian), `mathlive@0.101.0` (pinned, bundled), vitest.

**Spec:** `docs/superpowers/specs/2026-10-26-lyx-math-design.md` — read it before any task.

**Throwaway demo (reference only, not to be copied wholesale):** `docs/demo/demo.html` — contains the validated Space-to-finish handler, panel `GROUPS` list, and MathLive option settings.

- Branching: each task is built on its own branch off `main`, named `task/NN-<slug>` (e.g. `task/01-scaffold`, `task/02-braces`, `task/06-editor-session`). The task's commits go there; once its tests pass (and, for Tasks 6–9, the user has confirmed the manual check), merge into `main` with `git merge --no-ff` and delete the branch. Never commit task work directly to `main`. Plugin id `lyx-math`, name `LyX Math`, `isDesktopOnly: true`, `minAppVersion: "1.5.0"`.
- Install target: `<your vault>/.obsidian/plugins/` (files: `main.js`, `manifest.json`, `styles.css`, `fonts/`).
- `mathlive` pinned to exactly `0.101.0`, bundled; no CDN or network access at runtime.
- Notes stay plain Markdown: only `$...$` and `$$\n...\n$$`. No custom syntax, no hidden data.
- Default hotkeys: Ctrl+M (`Mod+M`) inline, Ctrl+Shift+M (`Mod+Shift+M`) display — as Obsidian commands, rebindable.
- MathLive automatisms OFF: `inlineShortcuts = {}`, `smartFence = false`, `smartSuperscript = false`, `smartMode = false`, `/` keybinding removed, `menuItems = []`, `mathVirtualKeyboardPolicy = 'manual'` (and hide its toggle). `inlineShortcuts`/`keybindings` throw before mount — set them after the element is connected.
- Saved LaTeX always braced: `\frac{4}{3}`, `\sqrt{2}`, `x^{2}`, `a_{1}`, `\hat{x}`, `\frac{a}{b}`, `x^{a}`.
- Unchanged formula (opened, closed, no edit) → original text byte-for-byte.

- Node.js is not installed: install with `winget install OpenJS.NodeJS.LTS`; in shells opened before install, call `"C:\Program Files\nodejs\npm.cmd"` by full path.

## Review Focus

1. Dollar signs that are not math — `\$5`, `` `code $x$` ``, "costs $5 and $6" with spaces — must not be treated as a formula by click or Ctrl+M. → test in Task 3 (`findMathAt`).
2. Display math inserted mid-line or at the very start/end of the file must land as `$$` / formula / `$$` on their own lines without eating neighbouring text. → test in Task 4 (`planCommit`).
3. A formula MathLive doesn't understand (`\begin{aligned}`, `\label`, `\tag`, a user macro, multi-line `$$`) must never be rewritten — it opens as raw text. → test in Task 3 (`needsRawFallback`).
4. Old notes with short forms (`\frac12`, `x^2`) opened and closed without change stay byte-identical. → test in Task 4 (`planCommit` with `dirty: false`).
5. The brace normalizer must not damage LaTeX it doesn't own: `\left(`, `\{`, `\\`, `x^{\prime}`, `^\circ`, `\text{a b}`, `x'`. → test in Task 2 (`lyxBraces`).

### Task 2: Brace normalizer `lyxBraces`

**Files:**
- Create: `src/latex/braces.ts`, `test/braces.test.ts`

**Interfaces:**
- Produces: `export function lyxBraces(latex: string): string` — pure, idempotent.

Approach (decided): a small LaTeX tokenizer (tokens: `\name` command, `\` + single non-letter symbol, `{...}` group, `[...]` optional arg after `\sqrt`, single char). Walk tokens: after `^` or `_`, if next token is not a `{}` group, wrap it in `{}`; after a command in `ARG_COUNT` (`frac 2, dfrac 2, tfrac 2, cfrac 2, binom 2, dbinom 2, tbinom 2, sqrt 1 (optional [..] first), hat, bar, vec, dot, ddot, tilde, widehat, widetilde, overline, underline, overrightarrow, overleftarrow, mathbb, mathcal, mathrm, mathbf, mathit, mathsf, boldsymbol, operatorname, text: 1`), wrap each non-group argument token. Recurse into groups. Whitespace preserved otherwise. Do not touch anything else.

### Task 3: Find math at a position; raw-fallback check

**Files:**
- Create: `src/latex/findMath.ts`, `test/findMath.test.ts`

**Interfaces:**
- Produces:
  - `export interface MathRange { from: number; to: number; inner: string; display: boolean }` — `from`/`to` cover the delimiters; `inner` is the text between them.
  - `export function findMathAt(doc: string, pos: number): MathRange | null` — the formula containing `pos` (inclusive of delimiters), else `null`.
  - `export function needsRawFallback(range: MathRange, validate: (latex: string) => unknown[]): boolean` — `validate` is MathLive's `validateLatex` injected (keeps tests DOM-free).

Rules (decided): `$$...$$` may span lines; `$...$` must be on one line, opening `$` not followed by space, closing `$` not preceded by space (Obsidian's rule); `\$` is never a delimiter; ignore `$` inside inline code spans (backticks) and fenced code blocks. Fallback is true if `inner` contains `\begin`, `\label`, `\tag`, or a newline after trimming, or `validate(inner.trim())` returns any error.

### Task 4: Commit planning (what text to write back)

**Files:**
- Create: `src/latex/commit.ts`, `test/commit.test.ts`

**Interfaces:**
- Consumes: `lyxBraces` (Task 2), `MathRange` (Task 3).
- Produces:
  - `export interface CommitInput { doc: string; target: MathRange | { from: number; to: number; display: boolean; inner?: undefined }; latex: string; dirty: boolean; exit: 'after' | 'before' | 'none' }` — `target` is the existing formula, or the insertion range (selection or empty) for a new one.
  - `export interface CommitPlan { from: number; to: number; insert: string; cursor: number | null }`
  - `export function planCommit(input: CommitInput): CommitPlan`

Rules (decided): existing formula with `dirty: false` → `insert` = original text unchanged. Otherwise `latex` is trimmed and passed through `lyxBraces`. Empty → delete the range (for display, also one adjacent newline so no blank `$$` line remains). Inline → `$latex$`. Display → `$$\nlatex\n$$`, adding a leading `\n` if `from` is not at a line start and a trailing `\n` if `to` is not at a line end. `cursor`: `'after'` → end of inserted text (after trailing newline for display), `'before'` → `from` (after the leading newline if one was added), `'none'` → `null`.
